# 视频诉求模板

首页写视频诉求时使用。先选视频类型，再用对应模板：把【】里的内容换成自己的，用不上的行可以删掉。时长、画面比例和语言在首页单独选，模板里不用写。

## 怎样写好诉求

- **用途与平台**：发在哪里，例如抖音、小红书、视频号、电商详情页、发布会大屏。
- **受众**：给谁看，他们最在意什么。
- **核心信息**：看完要记住的一到三件事。
- **主体外观**：产品或人物具体长什么样，写颜色、材质、形状和服装。这一项最影响各镜头画面是否一致。
- **风格**：画面、节奏、配音和音乐各要什么感觉。
- **必须有 / 不要有**：一定要出现的画面，以及要避开的画面。
- 不写品牌名，改写外观；画面里不需要文字，价格和卖点文字用叠加文字加。

## 一、商品广告

模板：

```
【用途】在【平台】投放的【新品推广 / 促销 / 详情页】广告。
【受众】【年龄、身份】，在意【痛点或需求】。
【产品】【品类名称，不写品牌名】：【颜色】【材质】【形状尺寸】，【外观特征，如 Logo 位置、包装样式】。
【卖点】按重要程度：1.【卖点一】 2.【卖点二】 3.【卖点三】。
【价格与引导】【价格或优惠】，结尾引导【下单 / 领券 / 进店】。
【开头】前 3 秒用【痛点场景 / 效果对比 / 产品特写】抓住注意力。
【场景】【使用场景，如厨房、办公桌、户外】。
【风格】画面【明亮干净 / 高级质感 / 生活化】，节奏【快 / 中等】，配音【亲切 / 专业 / 活泼】。
【必须有】【产品特写、使用过程、前后对比等】。
【不要有】【竞品、画面文字、夸大功效的表述等】。
```

例子：

```
在抖音投放的新品推广广告。受众是 25–35 岁的上班族，早上时间紧，想快速喝上一杯好咖啡。
产品是一台便携咖啡机：哑光白色机身，圆柱形，高约 20 厘米，顶部有一圈浅木纹盖子，正面一个银色圆形按键。
卖点：1. 一键 3 分钟出意式浓缩；2. 充一次电能做 15 杯；3. 能放进通勤包。
首发价 299 元，结尾引导点击购物车。
开头 3 秒用「早上手忙脚乱赶地铁」的场景，再切到办公桌上一键出咖啡。
场景：家里玄关、地铁、办公桌。画面明亮干净，节奏偏快，配音亲切有活力。
必须有：按下按键的特写、咖啡流出的特写、放进包里的动作。
不要有：其他品牌的咖啡杯、画面里的文字、「全网最好」之类的说法。
```

## 二、品牌宣传

模板：

```
【用途】在【官网 / 发布会 / 社交媒体】播放的品牌片。
【受众】【合作方 / 潜在客户 / 大众消费者】。
【品牌】【做什么的，不写品牌名】，核心理念是【一句话理念】。
【要传达】1.【价值观或主张】 2.【实力或背书，如工艺、团队、历程】 3.【对用户的承诺】。
【情绪】看完让人感到【温暖 / 信赖 / 振奋 / 高级】。
【叙事】【时间线 / 人物故事 / 产品诞生过程 / 用户群像】。
【人物与场景】【人物外观、服装】，场景【工厂、工作室、城市、自然等】。
【风格】画面【电影感 / 纪实 / 极简】，色调【暖 / 冷 / 自然】，节奏【舒缓 / 递进】，音乐【钢琴 / 弦乐 / 电子】。
【结尾】落在【理念画面 / Logo 定格】。
【必须有】【……】。
【不要有】【……】。
```

例子：

```
在官网首页和发布会播放的品牌片。受众是潜在的企业客户。
我们是一家做手工皮具的工作室，理念是「慢一点，用得久一点」。
要传达三件事：坚持手工缝制；每件皮具都可以终身保养；十年只做一件事。
看完让人感到可信、踏实。
叙事以一位老匠人一天的工作为线：清晨开门、裁皮、手缝、打磨，最后交到客户手里。
匠人约 60 岁，灰白短发，深蓝色围裙，戴老花镜。场景是一间有木桌和暖光台灯的老工作室。
画面纪实电影感，暖色调，节奏舒缓，配钢琴音乐。
结尾落在成品皮包放在木桌上的静物画面。
必须有：双手缝线的特写。
不要有：现代流水线机器、画面里的文字。
```

## 三、知识科普

模板：

```
【用途】在【平台】发布的科普短视频。
【受众】【小白 / 有基础的爱好者 / 学生】，现在对【主题】的误解或困惑是【……】。
【主题】讲清楚【一个具体问题，越小越好】。
【要点】按讲解顺序：1.【先抛出问题或反常识现象】 2.【原理一】 3.【原理二】 4.【结论或实用建议】。
【讲法】用【生活类比 / 动画示意 / 实拍演示】，避免【公式、术语堆砌】。
【画面】【实拍场景 / 示意动画 / 图表】，主体是【……】。
【风格】语气【轻松 / 严谨】，节奏【中等】，配音【清晰、语速适中】。
【必须有】【关键示意画面，如截面图、前后对比】。
【不要有】【错误示意、恐吓性画面、画面文字】。
```

例子：

```
在小红书发布的科普短视频。受众是刚开始自己做饭的年轻人，很多人以为不粘锅越贵越好、可以用钢丝球刷。
主题：不粘锅为什么会「粘」，怎么用才能用得久。
讲解顺序：1. 开头先展示一口新锅煎蛋不粘、半年后却粘锅的对比；2. 涂层是怎么起作用的（用「荷叶上的水珠」类比）；3. 高温空烧和硬物刮擦怎样损伤涂层；4. 三条实用建议：中小火、木铲或硅胶铲、软布清洗。
画面以厨房实拍为主，原理部分用简单的示意动画。
语气轻松，节奏中等，配音清晰、语速适中。
必须有：新锅和旧锅煎蛋的对比画面。
不要有：着火、冒浓烟这类吓人的画面，画面里的文字。
```

## 四、口播

模板：

```
【用途】在【平台】发布的口播视频，目的是【种草 / 观点分享 / 教学 / 答疑】。
【受众】【……】。
【主讲人】【性别、年龄感、发型、服装】，状态【亲切 / 专业 / 幽默】。
【观点】一句话观点：【……】。
【内容】1.【开场钩子，一句话抓注意力】 2.【论点或步骤一】 3.【论点或步骤二】 4.【总结与互动，如提问、引导关注】。
【场景】主讲人在【书房 / 门店 / 户外 / 纯色背景】。
【插入画面】讲到【……】时插入【产品特写 / 示意画面 / 实拍素材】。
【风格】口语化，句子短，节奏【快 / 中等】，背景音乐【轻 / 无】。
【必须有】【……】。
【不要有】【……】。
```

例子：

```
在视频号发布的口播视频，分享观点。受众是想开始健身但总坚持不下来的人。
主讲人是 30 岁左右的女性，黑色马尾，灰色运动套装，状态亲切、有说服力。
观点：健身坚持不下来，不是因为意志力差，而是一开始定的目标太大。
内容：1. 开场：「你是不是办了健身卡，只去了三次？」 2. 目标太大会让人一开始就有压力；3. 第一个月只定一个小目标，比如每周走路三次、每次 20 分钟；4. 结尾提问：「你最长坚持过多久？评论区说说。」
场景：明亮的客厅，背景有一张瑜伽垫和绿植。
讲到小目标时，插入散步、拉伸的画面。
口语化，句子短，节奏中等，背景音乐很轻。
不要有：器械大重量训练画面，画面里的文字。
```

## 五、原片改造（从原片导入时使用）

模板：

```
【用途】把手机拍的【原片内容】做成在【平台】发布的【广告 / 展示视频】。
【原片】拍的是【主体和动作】，场景是【……】，问题是【画面杂乱 / 光线差 / 手不好看 / 背景不合适】。
【要改的】【换手 / 换背景 / 重新打光 / 统一色调】，改成【目标效果】。
【要保留的】【产品外观、Logo、动作、原声】不能变。
【产品】【颜色】【材质】【形状】，【外观特征】。
【补充镜头】原片不够时，补【产品特写 / 使用场景 / 结尾画面】。
【文案与配音】旁白讲【卖点或要点】，配音【亲切 / 专业】；原声【保留 / 压低 / 去掉】。
【风格】画面【明亮干净 / 高级质感 / 生活化】，节奏【快 / 中等】。
【不要有】【……】。
```

例子：

```
把手机拍的护手霜试用原片做成在小红书发布的商品展示视频。
原片拍的是在办公桌上挤出护手霜、涂在手背上，问题是桌面杂乱、灯光偏黄。
要改的：背景换成浅米色的干净桌面，重新打成柔和的自然光。
要保留的：护手霜管身外观和挤出、涂抹的动作不能变。
产品是一支淡粉色软管，磨砂质感，长约 12 厘米，白色翻盖。
原片不够时，补一个护手霜放在花束旁的特写作为结尾。
旁白讲「不黏手、香味淡、随身带」三点，配音亲切；原声去掉。
画面明亮干净，节奏中等。
不要有：画面里的文字、其他护肤品。
```
