# 路线图

## v0.1：可用的骨架

- [x] Project / Shot / Asset 数据模型与项目存储
- [x] Provider 注册表：大模型（豆包 Seed、DeepSeek、Kimi、通义千问预设 + 自定义 OpenAI 兼容接口）、Edge 配音、静音配音、Pixabay、Pexels
- [x] 镜头级增量渲染：配音、镜头渲染、拼接、字幕、背景音乐
- [x] 字幕按像素宽度换行、行长均衡
- [x] `/api/v2`、命令行、进程内渲染队列
- [x] Pixabay 方向与画布一致的素材优先
- [x] Windows 一键启动脚本 `start.bat`
- [x] 网页界面：新建、分镜编辑（文案、画面来源、检索词、候选素材、锁定、排序）、声音、字幕、预览、渲染与下载

## v0.2：AI 画面

- [x] AI 视频：火山方舟 Seedance，文生视频 + 首帧图生视频，与豆包共用方舟 Key
- [x] AI 图片：火山方舟 Seedream / OpenAI 兼容文生图，渲染时自动加慢推镜头（Ken Burns）
- [x] 收费确认：生成按钮和渲染都需要显式确认；未确认的 AI 镜头改用素材检索
- [x] 收费任务提交不重试，结果无法确认时提示到控制台核对，避免重复扣费
- [x] AI 生成不可用时自动回退到素材检索
- 更多 AI 视频服务（Wavespeed、Muapi 等）改由 v0.5 的聚合 Provider 覆盖；参考素材与费用预估移到 v0.4

## v0.3：多语种、声音与素材（已完成）

- [x] 多语种视频：16 种语言，按语言选择配音声音和字幕字体（内置中日、韩、泰文字体，缺字时自动换用）
- [x] 一个视频生成多个语言版本（大模型翻译，画面共用）
- [x] 网页界面中文 / English 切换，服务名称在英文界面显示英文
- [x] 日志文件：记录收费任务 id、生成与渲染过程，按天切分
- [x] 视频诉求（最多 4096 字节）与目标时长，镜头数由大模型按时长决定
- [x] 渲染可以真正取消（终止正在运行的 FFmpeg），删除渲染中的项目需确认
- [x] 素材按来源分目录（ai-video / ai-image / stock / upload / music），旧项目启动时自动整理
- [x] 候选素材按画面来源显示，并提示其他来源还有几个候选
- [x] 背景音乐自动检索：大模型提炼风格检索词，Internet Archive 找候选，可试听切换
- [x] 背景音乐检索防重复提交（检索中再点返回 409），候选按曲目去重
- [x] 使用配音服务返回的逐词时间戳对齐字幕（Edge 提供；其他服务退回按字数分配）
- [x] 更多配音服务：Azure、硅基流动、MiniMax、ElevenLabs
- [x] 更多素材库：Coverr
- [x] 素材检索缓存（相同检索词 7 天内不重复请求）
- [x] 背景音乐按授权过滤（CC0 / CC BY / 公共领域），检索到的音乐放进单独的 music 目录
- [x] 服务端错误提示的英文版（按 Accept-Language 返回）
- [x] README 中英文版本、硬件要求与界面截图

v0.3 遗留，随 v0.4 处理：

- [ ] 旧项目里已检索的背景音乐仍在 `other/`，启动整理时归到 `music/`
- [ ] 授权文字「未标注授权」在英文界面显示英文
- [ ] 背景音乐先用试听地址展示，选中后再下载整首，缩短检索等待
- [ ] CC BY / BY-SA 曲目的作者和授权写进成片说明或发布包
- [ ] 补测试：`pick_audio_file`、`build_query` 和背景音乐检索接口

## v0.4（下一步）：商品广告

依据：模型已支持多参考主体、首尾帧和修改已有视频；市场上增长最快的是电商商品视频（见架构文档「市场分析与产品规划」）。

- [ ] Provider 能力声明：最长时长、参考图数量、是否出声音、关键帧、能否修改视频，界面按能力显示选项
- [ ] 主体库与产品参考：项目级上传产品图、人物设定、Logo、风格画面，镜头生成时作为参考（替代原「参考素材」）
- [ ] 原片导入与自动切镜：导入手机拍的原片，按画面变化切成镜头
- [ ] 首尾帧衔接：上一镜头的尾帧作为下一镜头的首帧
- [ ] 开头变体 A/B：同一视频生成多个开头，只重做第一个镜头
- [ ] 动态字幕：逐词高亮等短视频样式；逐词时间戳推广到 Azure、MiniMax 等支持的服务
- [ ] 文字与图形叠加：卖点、价格、Logo、购买引导，与字幕分开
- [ ] 转场效果；预览叠加 TikTok / Reels 平台安全区
- [ ] 草稿 / 成片两档与费用预估：草稿用低分辨率和快速模型，收费前显示预计费用，项目显示累计费用
- [ ] 发布包：按平台规格导出成片、封面、字幕和 publish.json（标题、简介、话题）
- [ ] AI 内容标识：渲染时写入 MP4 元数据，可选角标
- [ ] 本地接口 Host / Origin 校验（原在 v1.0）
- [ ] 收费任务可恢复：远端任务 id 写进项目，重启后继续轮询（原在 v1.0）
- [ ] Docker 镜像与 Windows 安装包，README 首屏演示动图（原在 v1.0）

## v0.5：改画面与补齐 SaaS

- [ ] 改画面：用提示词修改候选素材（Runway Aleph 2.0、Kling O3、Seedance），结果作为新候选；全片统一画风
- [ ] 聚合 Provider：Runway API / fal.ai，一把 Key 用多家模型；可灵官方接口
- [ ] 商品链接导入：Shopify 优先，抓取产品图和卖点生成分镜
- [ ] 品牌包：Logo、品牌色、字体、片尾样式
- [ ] 一键预设与行业模板：商品展示、开箱、对比、教程、口播；抖音竖屏、横屏科普
- [ ] 项目快照与带水印样片，方便给客户审片和修改
- [ ] 项目导出 / 导入

## v0.6：拓宽场景

- [ ] 章节与 3–10 分钟中长视频
- [ ] 参考广告复刻：提取参考广告的镜头结构和节奏（只借鉴结构，不复制画面）
- [ ] 口播与对口型镜头：配音作为音频参考，渲染时用模型音轨
- [ ] 长镜头延展：配音超过模型最长时长时延展视频，不再截断
- [ ] 背景音乐按情绪 / 节奏对齐镜头切换点
- [ ] 时间轴视图与拖拽排序
- [ ] MCP 服务：让 AI 智能体调用建项目、改镜头、渲染

## v1.0：正式发布

- [ ] 网页界面中配置 Provider（写入服务器配置文件）
- [ ] 外部任务队列（Redis），支持多实例
- [ ] GPU 编码与预览代理文件，加快渲染
- [ ] 可选发布插件：只接官方接口（YouTube、TikTok、抖音企业），逐个账号授权，每次发布确认

## 不做

- 用 Cookie 自动发布的账号矩阵
- 以数字人口播为核心卖点
- 自建模型或积分订阅
- 把整条视频交给模型一次生成、不再分镜
