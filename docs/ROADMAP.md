# 路线图

> 最后更新：2026-10-31。本文是唯一的路线图，版本计划、优先级和待办都写在这里。

## 产品定位

Shotwright 是开源、本地运行的分镜式 AI 短视频工作台：默认像「一句话出片」那么简单，需要时逐层展开到镜头级控制。

- 面向：需要经常、低成本做短视频的个人和小团队。重点人群是出海电商卖家。
- 不同于一键出片（小云雀等）：它出初稿，Shotwright 能出投放用的成片。始终以镜头为单位，用户能控制每个镜头。
- 不同于模型平台：不自建模型，把各家模型当作镜头的画面来源，用自己的 Key、收费前确认。
- 不同于剪辑软件：不做多轨自由剪辑，精剪通过工程文件交给专业软件。

核心差异：镜头级控制、实拍与 AI 混剪、口播按文字精剪、多家模型可选、费用透明、数据不出本机。

衡量改进效果看这四个数：每秒成片花费、首次可用率、平均重做次数、浪费金额（生成了但没用上的花费）。

## 推进顺序

按优先顺序分五个阶段，每个阶段做完、测试通过、提交后再进入下一个。每个阶段的通用验收标准：全部测试、e2e 和代码检查通过，文档和截图更新，在本机实际跑通。

1. **上手门槛**（已完成）：安装包和首次启动向导，是推广的前提。
2. **少花冤枉钱**（进行中）：关键帧默认先行、生成前检查、补救推荐、花费指标。省钱效果最明显。
3. **质量的尺子**（已完成）：质量基准集加每家模型的提示词调优。衡量后续一切改进都靠它。
4. **更简单的界面**：简洁模式，审片作为主界面。
5. **差异化与推广**：整片样片、单镜头花费上限、自动一致性评分；聚焦出海电商；改好 README 后集中发布。

各阶段的具体条目见下面按版本分的待办清单，这里只讲顺序，不重复列条目。

#### 少花冤枉钱

思路：把钱花在已经确认的东西上，用便宜的方式试错，生成出问题优先补救、不轻易重来。

花钱前：

- [x] 关键帧先行设为默认：AI 视频镜头还没有首帧、配了 AI 图片服务时，主按钮是「先出 3 张关键帧（推荐）」，直接生成视频退为次要按钮
- [x] 生成前检查（`services/precheck.py`，只看文字、不花钱）：画面描述里的手部特写、画面文字、多人互动、复杂动作、快速运镜、一个镜头塞多个动作，提示风险并给改写建议；和上一个镜头的描述完全相同时也会提醒；配了大模型时可一键让 AI 按建议改写；生成确认框和渲染前体检里同样列出
- [x] 配音超过模型单次上限时提示要分几段、费用约几倍，可一键按句子把文案拆成两个镜头
- [ ] 镜头与模型匹配：按实测推荐每类镜头用哪家（静物和空镜建议用 AI 图片加慢推）。**部分有**：每家模型的能力（时长档位、分辨率、单价）已统一声明，但没有按实测给出推荐
- [ ] 花费档位：一个「省钱 / 平衡 / 最好效果」滑块，自动选模型、画面来源和分辨率并说明理由。**新做**

花钱时：

- [x] 草稿档：AI 视频用较低分辨率生成，更快更省钱
- [ ] 整片样片：先用免费方式出整片，确认节奏和文案后再花钱。**部分有**：草稿档和预览已覆盖，缺「整片先跑一遍」的流程
- [ ] 固定种子重生成：低分辨率满意后改用高分辨率会重新抽卡，要在界面上提醒；种子参数目前没有接入。**新做**
- [ ] 单镜头花费上限：每个镜头最多花多少、最多生成几次，到上限建议换思路。**部分有**：项目级费用上限已有，单镜头级没有

花钱后：

- [x] 成片抽帧检查：用看图模型找手指和面部畸形、乱码文字
- [ ] 自动检查扩展到手部变形、颜色前后不一致、闪烁。**新做**
- [x] 能修就不重做（`services/remedy.py`）：检查出问题时按「不花钱 → 比重做便宜 → 要再花钱」给出补救建议。素材太短先调入出点或改慢放定格、分辨率不够先换素材、描述有风险先改描述、配音超长先拆镜头；重新生成永远排在最后。渲染前体检和生成前检查里都带这些建议
- [x] 带着问题去重做：把检查出的问题自动转成修改意见，先改描述再重做。**部分有**：审片页可按意见改写描述，但没有自动把问题清单填进去

花钱指标：

- [x] 每秒成片花费、首次可用率、平均重做次数、浪费金额（`services/spend.py`）：按项目累计花费和每个版本的记录算出来，接口 `GET /projects/{id}/spend`，渲染面板里显示。成片时长用最近一次渲染的结果，还没渲染时按配音估算。每个生成版本记了花费（`Take.cost`），所以能算出「生成了但没用上」的钱

#### 视频质量

- [x] 质量基准集（`shotwright bench`）：固定 5 条核心诉求（商品、品牌、科普、口播、原片改造）× 横竖屏，一条命令跑出分镜、提示词和成片并存档
- [x] 基准集扩到 15 条：`tier=core` 是最早的 5 条，指标口径固定、日常改动跑这一组就够（`shotwright bench --tier core`）；`tier=extra` 是 10 条难度用例（静物商品、数码、多人家庭、餐饮、时装、理财、健康、专家口播、带货口播、旅行原片），完整评测时一起跑
- [x] 每家模型单独调提示词（`services/model_rules.py`）：声明各模型的提示词预算和建议描述长度，拼提示词时超预算先丢风格和场景，主体外观、参考图要求和禁止项永远保留；海螺另外加一句「一个镜头只表现一个动作」。分镜自检也按最终要用的模型查长度，写太长时要求重写一次
- [ ] 用基准集对比各家模型的提示词效果。**新做**：规则已就位，需要在真实模型上各跑一遍基准集才谈得上调优
- [ ] 自动一致性评分：每个镜头对比参考图打分，审片时问题镜头排在前面。**部分有**：看图模型已能评估候选素材，但没有镜头级一致性分
- [ ] 从用户选择里学习：在本地积累选了哪个版本、重做原因、修改意见，改进选模型和提示词。**新做**

#### 剪辑与素材

## 护城河

功能本身构不成护城河（大厂几周就能做出来，开源代码也能被复制），要守住的是别人拿不走、短期追不上的东西。

| 层次 | 内容 |
| --- | --- |
| 「怎么做出好视频」的经验 | 由基准集和提示词调优持续积累，新模型几天内给出最佳用法 |
| 用户资产沉淀 | 品牌包、主体库跨项目复用，模板和读音纠正表；格式开放、不锁数据 |
| 聚焦出海电商 | 产品一致性做到行业最好，一键出多国版本，海外平台规格合规，商品链接导入 |
| 生态 | 社区接入新模型、共享模板；MCP 服务，让智能体直接调用 |
| 中立和信任 | 不绑定模型、数据不出本机、费用透明、开源可私有部署 |

不要指望的护城河：功能数量、独家模型、锁住用户数据。

### 视频质量专项

目标：让成片质量稳定可用。问题主要出在「从诉求到画面」这一段：诉求常常只有一句话，大模型每个镜头只写一句约 20 词的画面提示词，镜头之间互不衔接，人物和产品外观全靠模型猜；镜头不够长时只能慢放、定格或循环；声音也没有做响度和闪避处理。

> 看图检查（产品保真、素材排序、成片抽帧）需要在大模型配置里填 `vision_model`；接入真实大模型后先跑一次 `shotwright bench --render` 作为基线。

验收标准（用质量基准集逐批对比，结果存档）：

- 提示词：每个 AI 镜头的画面描述达到规定长度，衔接说明覆盖全部相邻镜头
- 一致性：同一产品和人物在各镜头间的看图模型一致性评分提升
- 节奏：慢放、定格、循环镜头的占比下降
- 声音：成片响度在 -14 LUFS ±1 LU 以内，有配音时背景音乐不压人声

通用要求：

- 提示词语言：界面上展示和编辑用项目语言，提交给模型时按 Provider 能力决定是否翻译成英文，用户不用读写英文
- 费用：会增加收费调用的功能（关键帧、多候选、看图检查、续生成），草稿档默认关闭，生成前显示预计费用；项目可设费用上限，超出前提示
- 老项目：没有全片设定或提示词偏短的项目，打开时提示一键补全，不自动收费
