# 路线图

## 产品定位

Shotwright 是开源、可自部署的短视频分镜生产工具：从一段视频诉求出发，按镜头生成或检索画面、配音、字幕和音乐，每个镜头都能单独选来源、替换、重做和剪辑，改一个镜头只重渲这个镜头。

- 面向：需要经常、低成本做短视频的个人和小团队，重点场景是商品广告。
- 不同于一键成片：始终以镜头为单位，用户能控制每个镜头。
- 不同于模型平台：不自建模型，把各家模型当作镜头的画面来源，用自己的 Key、收费前确认。
- 不同于剪辑软件：不做多轨自由剪辑，精剪通过工程文件交给专业软件。
- 当前阶段先把成片质量做好，暂不考虑商用相关功能。

## 视频质量专项（已完成，待实测）

目标：让成片质量稳定可用。问题主要出在「从诉求到画面」这一段：诉求常常只有一句话，大模型每个镜头只写一句约 20 词的画面提示词，镜头之间互不衔接，人物和产品外观全靠模型猜；镜头不够长时只能慢放、定格或循环；声音也没有做响度和闪避处理。

开始条件：v0.4 先在方舟实测 Seedance 2.5 并发布；改画面如果实测不顺，先标为实验功能，不阻塞发布。

> 状态：全部实现。看图检查（产品保真、素材排序、成片抽帧）需要在大模型配置里填 vision_model；接入真实大模型后先跑一次 `shotwright bench --render` 作为基线。

验收标准（用质量基准集逐批对比，结果存档）：

- 提示词：每个 AI 镜头的画面描述达到规定长度，衔接说明覆盖全部相邻镜头
- 一致性：同一产品和人物在各镜头间的看图模型一致性评分提升
- 节奏：慢放、定格、循环镜头的占比下降
- 声音：成片响度在 -14 LUFS ±1 LU 以内，有配音时背景音乐不压人声

通用要求：

- 提示词语言：界面上展示和编辑用项目语言，提交给模型时按 Provider 能力决定是否翻译成英文，用户不用读写英文
- 费用：会增加收费调用的功能（关键帧、多候选、看图检查、续生成），草稿档默认关闭，生成前显示预计费用；项目可设费用上限，超出前提示
- 老项目：没有全片设定或提示词偏短的项目，打开时提示一键补全，不自动收费
